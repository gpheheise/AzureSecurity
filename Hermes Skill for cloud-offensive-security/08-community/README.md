# Community

The people, blogs, podcasts, and conferences worth following. Cloud offensive security is a small field. The same dozen or so researchers drive most of the public technique catalog. Know them.

## People to follow

Organized by primary platform focus. Most cross-pollinate.

### Azure / Entra ID / M365

**Dirk-jan Mollema** ([@_dirkjan](https://x.com/_dirkjan)) - Outsider Security founder. Author of ROADtools, MITM6, krbrelayx, mitm6, lots of impacket contributions. The single most influential Entra ID offensive researcher. Discovered CVE-2025-55241 (Actor Token cross-tenant compromise) in July 2025. Blog: https://dirkjanm.io. Conference circuit regular at Black Hat, DEF CON, TROOPERS.

**Fabian Bader** ([@fabian.bader.cloud](https://infosec.exchange/@fabian.bader.cloud)) - Microsoft MVP based in Germany. Co-presented with Mollema on multiple Conditional Access bypass talks. Author of TokenTacticsV2. Blog: https://cloudbrothers.info. Strong defensive content alongside offensive research, which makes him uniquely valuable.

**Beau Bullock** ([@dafthack](https://x.com/dafthack)) - TrustedSec. Author of GraphRunner, MFASweep, PowerMeta. Long-running M365 attack research. Blog: https://trustedsec.com/blog/author/beau-bullock.

**Andy Robbins** ([@_wald0](https://x.com/_wald0)) - SpecterOps. BloodHound co-author. Drove AzureHound development. Identity attack path research is his lane. Blog: https://posts.specterops.io/@_wald0.

**Karl Fosaaen** ([@kfosaaen](https://x.com/kfosaaen)) - NetSPI. MicroBurst author. Long catalog of Azure offensive techniques. Blog at https://www.netspi.com/blog/author/karlfosaaen.

**Lars Karlslund** ([@lkarlslund](https://github.com/lkarlslund)) - AzureHound maintainer, ADalanche author. Identity attack graph focus.

**Joosua Santasalo** ([@SantasaloJoosua](https://x.com/SantasaloJoosua)) - Identity protection research, Microsoft cloud detection.

**Roberto Rodriguez** ([@Cyb3rWard0g](https://x.com/Cyb3rWard0g)) - Threat hunting and detection engineering for M365 / Azure. Multi-disciplinary, ex-Microsoft. Atomic Red Team contributor.

### AWS

**Nick Frichette** ([@frichette_n](https://x.com/frichette_n)) - Datadog. hackingthe.cloud maintainer. Prolific AWS technique researcher. Blog: https://frichetten.com.

**Christophe Tafani-Dereeper** ([@christophetd](https://x.com/christophetd)) - Datadog. Author of Stratus Red Team and CloudFlare adversarial emulation work. Blog: https://christophetd.fr.

**Scott Piper** ([@0xdabbad00](https://x.com/0xdabbad00)) - Summit Route. Founder of fwd:cloudsec. AWS security elder statesman. flAWS / flAWS2 author. Blog: https://summitroute.com/blog. Wiz Research now.

**Houston Hopkins** ([@houstonhopkins](https://x.com/houstonhopkins)) - AWS / cloud detection engineering.

**Aidan Steele** ([@__steele](https://x.com/__steele)) - Independent. Deep AWS internals research, especially around STS, signing, undocumented behavior.

**Gafnit Amiga** ([@gafnitav](https://x.com/gafnitav)) - Wiz Research. Discovered several AWS service vulnerabilities including RDS, ECR, AWS SSM.

**Shir Tamari** ([@shirtamari](https://x.com/shirtamari)) - Wiz Research. Co-discovered major AWS vulns including ChaosDB, OMIGOD.

**Rami McCarthy** ([@ramimacisabird](https://x.com/ramimacisabird)) - Cloud security generalist, frequent blogger on AWS topics. Now at Wiz.

### GCP

**Allison Donovan** ([@allidonovan](https://x.com/allidonovan)) - GCP security research, formerly Mandiant.

**Chris Moberly** ([@_init_5](https://x.com/_init_5)) - GitLab security team. GCP attack research, especially around Cloud Functions and IAM.

**Spencer Gietzen** ([@SpenGietz](https://x.com/SpenGietz)) - Rhino Security Labs alum. Authored the Rhino GCP privesc methodology. AWS Pacu original author.

GCP has fewer dedicated researchers than AWS or Azure. Most GCP content comes from generalist cloud researchers or one-off blog posts. Watch the Wiz Research blog for the biggest GCP findings.

### Multi-cloud and platform-agnostic

**Houston Hopkins, Rich Mogull, Marco Lancini** - All maintain useful generalist content.

**Marco Lancini** ([@lancinimarco](https://x.com/lancinimarco)) - Cloud Security Forum founder. Newsletter: https://cloudseclist.com is the single best curated weekly cloud security digest.

**Daniel Grzelak** ([@dagrz](https://x.com/dagrz)) - Plerion founder. AWS attack research, including the seminal "AWS attribute-based access control" work.

**Bishop Fox cloud team** - Collectively publish strong research. Notable members include Gerben Janssen van Doorn.

**Wiz Research team** - Industrial-scale cloud vuln research. The team behind ChaosDB, OMIGOD, AttachMe, BingBang. Blog: https://www.wiz.io/blog/category/research.

**Datadog Security Labs team** - https://securitylabs.datadoghq.com. Frichette, Tafani-Dereeper, others.

**SpecterOps team** - Beyond Robbins, the full BloodHound and identity attack research group.

## Podcasts

Limited but worth your time:

- **Cloud Security Podcast** (Ashish Rajan and Shilpi Bhattacharjee) - https://cloudsecuritypodcast.tv/. Weekly. Industry voices, sometimes deep technical.
- **Risky Business** (Patrick Gray) - https://risky.biz/. Weekly news. Cloud surfaces frequently. Australian, smart, sharp.
- **Entra.News** (Merill Fernando) - https://entra.news/. Weekly Entra ID newsletter and podcast format. Defender-flavored but offensive-relevant.
- **Cyberwire Daily** - Daily news roundup. Background listening.
- **Detection at Scale** (Jack Naglieri) - Detection engineering. Useful to know what your work will trip.

Cloud-specific deep-dive podcasts are surprisingly rare. Most good research lands on YouTube as conference talks, not audio.

## Conferences

### Cloud-focused

- **fwd:cloudsec** ([fwdcloudsec.org](https://fwdcloudsec.org)) - The cloud security conference. Multiple editions: North America (Salt Lake City typically), Europe (recent: Berlin), Brazil. CFP-driven, no vendor pitches, single-track. The conference for serious cloud security work.
- **DEF CON Cloud Village** - Annual Las Vegas. Talks, workshops, contests. Variable quality but always has standouts.
- **CloudNativeSecurityCon (CNCF)** - Container and K8s security focus. North America and Europe editions.

### General security with strong cloud tracks

- **Black Hat USA / EU / Asia** - Premier vendor conference. Multiple cloud tracks. Expensive.
- **DEF CON** - Las Vegas annual. Cloud Village plus mainline talks.
- **RSA Conference** - San Francisco annual. Cloud track present, vendor-heavy overall.
- **TROOPERS** ([troopers.de](https://troopers.de)) - Heidelberg, Germany. Strong technical content. DACH-region accessible.
- **NorthSec** - Montréal. CTF-heavy. Cloud topics increasingly common.
- **Insomni'hack** - Geneva. Swiss/DACH-adjacent. Cloud content present.
- **BSidesLV** - Las Vegas alongside DEF CON. Free or cheap, strong content.
- **OWASP Global AppSec EU / US** - AppSec focus but cloud crossover.
- **M3AAWG** - Email/identity abuse. Adjacent to M365 offensive work.

### DACH-specific

- **TROOPERS** - Heidelberg, June. Already mentioned, worth repeating.
- **Heise IT-Security Tagung** - German enterprise security conference.
- **it-sa Nuremberg** - Enterprise security expo. Vendor-heavy, networking value.
- **Hack.lu** - Luxembourg, October. Technical content. Adjacent to DACH.
- **Area41** - Zurich. Swiss conference, strong technical bent.

## Communities and Discord/Slack servers

- **Cloud Security Forum Slack** (Marco Lancini) - Free to join. Most active cloud security community I know of. Active channels for AWS, Azure, GCP, K8s, audit, careers, jobs.
- **BloodHound Slack** - SpecterOps-run. Identity attack focus.
- **OWASP Slack** - Multiple cloud-relevant channels.
- **DEF CON Discord** - Cloud Village channels.
- **HTB Discord** - Cloud topic channels.
- **Pwned Labs Discord** - Course-specific support and discussion.

- **CloudSecList** (Marco Lancini) - https://cloudseclist.com. Weekly. The single most valuable cloud security newsletter.
